# 02. 構成要素・動作環境

> 状態: 初版(2026-10-03)

## 2.1 構成要素

```
┌──────────────────────────── FocusCoach.App(WPF、タスクトレイ常駐、単一プロセス) ─┐
│  画面: ホーム / 開始準備 / 作業中ミニパネル / 演出オーバーレイ / 振り返り / 管理 / 設定  │
```

| 要素 | 役割 | 備考 |
|------|------|------|
| FocusCoach.App | UIと常駐。ホットキー、トレイ、各画面 | 1ユーザーにつき1プロセス(多重起動を禁止) |
| FocusCoach.Core | ドメインロジック全般 | UIとOSに依存しない。ヘッドレスでテスト・リプレイできる([08](08-debug-logging.md)) |
| Platform.Windows | Win32/COMを使ったOS連携 | インターフェース越しにCoreへイベントを渡す。テストではFakeに差し替える |
| Audio | BGM・効果音・録音 | NAudio |
| Transcription | 音声メモのテキスト化 | ローカル実行が既定。外部ツール用の書き出しにも対応する |
| Storage | 永続化 | `%LOCALAPPDATA%\FocusCoach\` 配下に置く([04](04-data.md)) |
| FocusCoach.Cli | デバッグ・検証用のコマンドライン | シナリオ実行、リプレイ、診断([08](08-debug-logging.md)) |

## 2.2 動作環境

| 項目 | 要件 |
|------|------|
| OS | Windows 10 22H2 / Windows 11(x64) |
| 権限 | **一般ユーザー権限で全機能が動くこと**(必須要件)。管理者権限やグループポリシーの変更を要する方式は採用しない |
| ランタイム | .NET 8(self-contained で配布し、ランタイムの事前インストールを不要にする) |
| 画面 | マルチモニタと、モニタごとのDPI(Per-Monitor DPI v2)に対応 |
| 音声 | ヘッドセット/イヤホンとマイク(Web会議用のもの)。BGMは既定の出力デバイスで再生する |
| ネットワーク | 任意。ネットワークが無くても全機能が動く。ファイルサーバ(UNCパス)や社内Webシステムへのアクセスはユーザーの通常操作として発生するもので、本ツール自身は通信しない |
| ブラウザ | Microsoft Edge / Google Chrome(URL記録の対象)。Firefoxは履歴DBの形式が異なるためMVPでは対象外 |
| ディスク | 本体 約200MB(音声認識モデルを含む)+ データ。音声メモ1分あたり約0.5MB(Opus) |

## 2.3 業務端末での制約と配慮

- **情報漏えいへの配慮**: 記録するウィンドウタイトル、ファイルパス、URLには業務上の機密が含まれうる。既定では**すべてローカルに保存し、外部へ送信しない**。オンラインの文字起こしやAIコメントなど外部サービスを使う機能は、明示的なオプトインとする。
- **ブラウザ拡張の導入可否**: 企業ポリシーで拡張機能の導入が制限されている場合があるため、拡張機能に依存しないURL記録方式をMVPの標準とする([05](05-functions.md) F-06)。
- **社内規程の確認**: PC操作の記録(本人用であっても)が社内規程に抵触しないか、導入前に利用者が確認する。設定画面に記録対象と保存場所を明示する。

## 2.4 開発環境

| 環境 | できること |
|------|-----------|
| ローカルのWindows PC | すべて(ビルド、テスト、実機での起動と動作確認) |
| Claude Code クラウドセッション(Linux コンテナ) | Core / Storage / Cli のビルドとテスト、シナリオ実行、仕様書の編集。Platform.Windows は `EnableWindowsTargeting` によるコンパイル確認まで(実行はできない)。WPF(App)は Linux の SDK にビルド機構が無いため、コードビハインドの型チェック(`scripts/check-app-codebehind.sh`)のみ |

クラウドセッションで作業を分担する方針は [07-tech-stack.md](07-tech-stack.md) §7.5 を参照。
