## 3.3 各画面の構成要素

### S-02 開始準備(ガイド)

```
┌ 開発計画書作成 ─────────────────────────────── 前回 1h52m / 中央値 2h05m ┐
│ プロジェクト名: [ XXシステム更改          ]   目標時間: [ 1h45m ] (前回-7分)│
│                                                                          │
│  # サブタスク            目安(中央値) 前回    資料(前回開いたもの)        │
│  1 見積書の確認              12m     10m    📁 \\fs01\見積\…  🌐 見積管理  │
│  2 概略仕様の確認            25m     31m    📄 概略仕様書.docx            │
│  3 担当作業メンバの確認       8m      7m    🌐 要員管理システム            │
│  4 スケジュールの確認        15m     14m    📄 マスタスケジュール.xlsx     │
│  5 本文作成                  60m     50m    —                             │
│  [+ サブタスク追加] [並べ替え]                                             │
│                                                                          │
│ ワークスペース: (●) 他ウィンドウを最小化  残すアプリ: [Teams ×][Outlook ×] │
│ BGM: [ブラウンノイズ ▼]  演出: [ON]                                         │
│                                         [ キャンセル ]  [ ▶ 集中を始める ]│
└──────────────────────────────────────────────────────────────────────────┘
```

- 実装は、上の図の簡易版(0.8A、0.10A で変更): タスク(入力もできるプルダウン)、プロジェクト、手順(表示と [手順を編集])、作業で使うアプリ、最初の一手、過去の実績からのガイド、練習モード、[集中を始める]。
- **タスク欄はプルダウン**。実行したことがある(中止・中断中を含む)タスク、手順を登録したタスク、下書きがあるタスクを、最近使った順に出す(回数・最終日・手順登録済み・入力のみを添える)。選ぶと、登録した手順(無ければ前回入力した手順、前回の実行の手順)と、前回入力したプロジェクト・使うアプリ・最初の一手が入る(05 F-01)。新しいタスクは名前を入力する。
- **既定は空から始める(0.10A)**。起動時と、タスクを終えて開始準備に戻ったときは、タスク名・プロジェクト・手順・最初の一手を空にする(前回と同じタスクをまた始めることは少ないため)。タスク欄が空の間は「タスクを選ぶか、名前を入力」と薄く出し、[集中を始める] は押せない(下に案内を出す)。
- プルダウンの行を右クリック →「一覧から外す」で、そのタスクを一覧から外せる(実行の記録・手順・下書きは消さない。同じ名前を使うと一覧に戻る)。
- 上部に「中断中の実行」(`suspended` / 異常終了した実行)を並べ、選んで再開できる(F-15、F-16)。
- 「タスクで使うアプリ」を選べる(F-02)。
- 実績が無い種別(初回)では目安列を「—」とし、サブタスクを手入力するか、似た種別からコピーする。
- 資料列はプロジェクトによって中身が変わる。扱いは [05](05-functions.md) F-02 と U-05-1 を参照。

### S-02a 手順エディタ(0.8A で追加)

開始準備の [手順を編集] から開くダイアログ。手順を登録しておくと、次回からタスクを選ぶだけで入る([05](05-functions.md) F-01)。

```
┌ 手順の編集 ───────────────────────────────────┐
│ タスク: 開発計画書作成                          │
│    手順の名前                   目安(分)        │
│ 1 [ 見積確認            ]  [ 25 ]  [↑][↓][×]   │
│ 2 [ 概略仕様確認        ]  [ 25 ]  [↑][↓][×]   │
│ 3 [ 執筆                ]  [ 40 ]  [↑][↓][×]   │
│ [+ 手順を追加]                                  │
│ Enter で次の行へ。目安は空欄でもかまいません    │
│ [✓] このタスクの手順として登録する              │
│                          [キャンセル] [決定]    │
└───────────────────────────────────────────────┘
```

- Enter で次の行へ移る(名前 → 目安 → 次の行の名前)。最後の行で Enter を押すと行を追加する。Esc でキャンセル。
- 入力に問題があれば、ダイアログの下に琥珀色で理由を出し、閉じない(重複、使えない文字、目安の範囲など。05 F-01)。
- タスク名が未入力のときは「登録する」を選べない(この回だけの手順として使う)。
- タスク名が出るので、画面共有・録画には映さない(09章 §9.4.6)。

### S-04 作業中ミニパネル

```
┌──────────────────────────────────────────┐
│ ② 概略仕様の確認        18:24 / 目安 25:00 │  ← サブタスク時間(目安超過で色が変わる)
│ ▓▓▓▓▓▓▓▓▓▓▓▓░░░░░  全体 0:31:10 / 1:45:00 │
│ [✓完了→次へ] [⏭スキップ] [📂資料] [📝メモ] [🎙録音] │
│ [⚡割り込み] [📥トレイ] [⏸一時停止] [♪BGM] [■タスク終了] │
└──────────────────────────────────────────┘
```

- 画面の端にスナップする。折りたたむと1行表示(サブタスク名とタイマーのみ)になる。
- フォーカスを奪わない。クリックしても作業中のウィンドウのフォーカスを維持する。WS_EX_NOACTIVATE に加えて、`WM_MOUSEACTIVATE` に `MA_NOACTIVATE` を返す(0.4A の実機確認で、ボタンのクリックでフォーカスを奪ったため。R-45)。
- 文字入力が要る操作(メモ)は、別の小さな入力ウィンドウで行う。入力の間だけアクティブになり、閉じたら元のウィンドウにフォーカスを返す。
- グローバルホットキー: **F9 = 割り込み ⇄ 再開、F10 = メモ**(作業中は棚上げ、割り込み中は再開メモ「どこまで / 次の一手」)。[09](09-focus-advice.md) §9.4.1。設定で変更できる。登録に失敗したキーはミニパネルに表示する。
- 画面共有・録画に映らないようにする(`WDA_EXCLUDEFROMCAPTURE`。[09](09-focus-advice.md) §9.4.6)。
- **タイトル帯のボタン(0.10A)**: 右上に Windows 標準と同じ並びと大きさ(46×34px)で `[コンパクト表示] [最小化] [アプリを閉じる]`。✕ はマウスを重ねると落ち着いた赤みが出る(強い赤は使わない)。作業中のパネルにあった「終了」は「**タスク完了**」に改め、アプリを閉じる ✕ と取り違えないようにした(タスク完了はタスクを終えて振り返りを見る操作で、アプリは閉じない)。

### S-04b コンパクト表示(0.10A で追加)

画面を必要な要素だけに縮め、背景を透過して、下の画面の操作・視認をできるだけ妨げない表示。タイトル帯の [コンパクト表示] ボタン、またはホットキー **F8**(もう一度押すと元に戻る。作業中・開始準備のどちらでも使える)で切り替える。

```
 ┃ ● 概略仕様確認  0:18:24        ← 約 170×36px。左端の色帯と点が状態の色(通常=青緑 / 目安超過=琥珀 / 割り込みアプリ=青 / 中断中=灰青+❚❚)
```

- 中身は、状態の色帯・点、サブタスク名、サブタスクの経過時間、状態の記号だけ。開始準備のときは「FOCUS COACH 待機中」。
- **半透明**: 通常は不透明度 55%。文字には薄い影を付け、下の画面が透けても読めるようにする。マウスを重ねるとさらに薄く(20%)なり、下の画面が見える。
- **クリック透過**: 表示の上のクリックは下のアプリに通る(拡張スタイル `WS_EX_TRANSPARENT`)。フォーカスも奪わない。**Ctrl を押しながらマウスを重ねている間だけ**、不透明になってクリックを受け付け、[元に戻す] ボタンの操作とドラッグでの移動ができる。F8 を登録できなかったとき(他のアプリが使用中)は、元に戻せなくならないよう、クリック透過にしない。
- 見た目の判断(クリック透過にするか・不透明度)は Core の `HudPolicy`(テスト済みの純粋関数)で決め、App は反映だけを行う。設定(settings.json): `HotkeyCompact`(既定 F8)、`CompactOpacity`(0.55)、`CompactHoverOpacity`(0.2)、`CompactClickThrough`(true)。
- **一時的に元の表示に戻す**: コンパクト表示の間に、利用者に見せる必要があるもの(離席の問いかけ、復帰カード、閉じる確認、タスク完了の流れ)が出るときは、自動で元の表示に戻り、それらが閉じたら(自動で畳まれた場合も)コンパクト表示に戻る。F9 / F10 はコンパクト表示のままでも使える。
- **位置(0.11A)**: 元のウィンドウの**左上を起点**に縮む(左上の角は動かない)。戻すときは、コンパクト表示の**左上**に元のウィンドウの左上を合わせる(コンパクト表示を動かしていれば、その場所に戻る)。どちらも、画面の外にはみ出さないよう、全モニタをつなげた領域の中に収める(判断は Core の `HudPlacement`。テスト済み)。位置は保存しない。画面共有・録画には映さない(09章 §9.4.6)。起動時はいつも通常表示から始める。
- 実装: 透過(`AllowsTransparency`)はウィンドウを作った後に切り替えられないため、メインのウィンドウとは別のウィンドウ(`CompactHud`)にし、コンパクト表示の間はメインを隠す(ホットキーとロック・スリープの通知は、隠れたメインに届き続ける)。

- 位置を保存し、次回も同じ位置に出す。モニタ構成が変わって画面外になる場合は、主モニタの右上に戻す。DPI は PerMonitorV2 で扱う。
- 実行中に閉じようとしたら、[終了する] [中断して後日再開] [キャンセル] を選ばせる(F-15 の持ち越し)。
- アプリは同時に1つだけ起動する。2つ目の起動では、既存のウィンドウを前に出す(0.7A 時点は、案内を出して終了する。[仮案-31])。
- 0.7A 時点の実装は、上の図のうち「次へ・スキップ・割り込み・メモ・あとで続ける(中断)・終了」と、最初の一手の表示まで。資料・録音・トレイ・BGM は未実装。ボタンの文言と配置は §3.4.1 に従う。

### S-07 振り返り

- 上段: 総時間・実作業時間・集中スコアを、前回と中央値の差分付きで表示する(例:「-12分」は緑、「+5分」は橙)。
- 中段: サブタスクごとの時間の横棒グラフ(今回/前回/中央値)と、集中度タイムライン(5分刻みのヒートストリップ)。
- 下段: 改善ポイント(最大3件。ルールベースで抽出、[05](05-functions.md) F-11)、作業メモ一覧(音声メモは再生とテキスト)、アクセスした資料一覧(次回のランチャーに載せるかどうかを選べる)。

## 3.4 共通方針

- 作業中に出す要素(S-04、S-11)は小さく、閉じやすく、フォーカスを奪わないものとする。
- 演出はすべて設定で無効にできる。また Esc またはクリックでスキップできる。

### 3.4.1 ビジュアルの方針(2026-10-04 決定。U-03-1)

「ソフトウェアが業務の遂行を支える、近未来のシステム」を感じさせつつ、作業の邪魔をしない落ち着いた見た目にする。定義は `src/FocusCoach.App/App.xaml` に集約し、画面ごとに色や書体を直接書かない。

| 項目 | 方針 |
|------|------|
| 背景 | 深い青緑のダーク(`#0E1A20`)。面は2段階(`#14252D`、`#1A3039`)、区切り線は `#28434E` |
| アクセント | 青緑 `#4FD1C5` と青 `#6CB4EE`。主ボタンとタイトル帯の線は、青緑→青のグラデーション |
| 状態の色(09章 §9.4.4) | 通常: 区切り線の色 / 目安超過: 柔らかい琥珀 `#E3C27A` / 割り込みアプリに滞在: 青 / 中断中: 灰青 `#7D919B`。**強い赤・橙は使わない**(心理的な負荷を下げる)。色だけに頼らず、記号(● ◆ ❚❚)と文言も添える |
| 文字 | 本文は BIZ UDPゴシック(ユニバーサルデザイン書体、Windows 10 以降に標準搭載)。時刻・数字・英字ラベルは Bahnschrift。無い環境では Yu Gothic UI / Meiryo UI |
| 文字の大きさ | 本文 13px、見出し 18px、サブタスクの経過時間 34px。補足は 11〜12px の淡い色 |
| 形 | 角丸(ボタン 6px、カード 8px)、細い枠。ホバーで青く光る |
| タイトル帯 | 独自の細い帯(WindowChrome)。左に状態の点(待機中: 灰 / 作業中: 青緑 / 中断中: 灰青)と「FOCUS COACH」、右に最小化・閉じる |
| 作業中の表示 | 「STEP 2 / 3」→ サブタスク名 → 大きな経過時間と目安 → 細い進み具合のバー(目安超過で琥珀色)→ 全体の経過時間 |
| 文言 | 短く、指示しない(06章 §6.4、09章 §9.3)。例: 「集中を始める」「完了して次へ」「あとで続ける」「目安の時間を過ぎています」 |

- テーマは当面ダークのみとする(OS のライト/ダーク設定への追従は将来の検討。U-03-3)。
- 標準のメッセージボックス(閉じる確認・振り返り・エラー)は OS の見た目のまま。振り返りは P-5 で独自の画面(S-07)にする。

## 3.5 タスクトレイとアイコン(0.11A で追加)

### 最小化とタスクトレイ

- タイトル帯の [最小化] ボタン、Win+M、タスクバーのボタンからの最小化は、**タスクバーではなくタスクトレイに格納する**(ウィンドウを隠す。タスクバーのボタンも消える)。
- タスクトレイのアイコンは起動中は常に出す。**左クリック**で格納前の表示(通常表示かコンパクト表示)に戻る。**右クリック**のメニューは `開く` / `割り込み対応 F9`(対応中は `元の作業へ F9`。作業中だけ押せる。0.12A)/ `コンパクト表示 F8`(コンパクト表示中は `通常表示に戻す F8`)/ `あとでやること`(0.12A)/ `Language / 言語`(日本語・English。0.13A。§3.7)/ `アプリを閉じる`。
- トレイに格納している間も、F8(コンパクト表示)・F9(割り込み)・F10(メモ)は使える。F8 を押すと、トレイからコンパクト表示になる。離席の問いかけ・復帰カード・閉じる確認が出るときは、一時的に元の表示に戻り、閉じたらトレイに戻る(コンパクト表示と同じ。S-04b)。
- **2つ目の起動**は、案内ダイアログを出さず、起動中の FocusCoach に合図して終了する(トレイに格納中でも、格納前の表示が出る)。
- 初めて格納したときだけ、吹き出しで場所を知らせる(設定 `TrayHintShown`)。Windows 11 は新しいアイコンを「^」の中に入れることがあるため。
- ツールチップには状態(待機中・作業中・中断中)だけを出す。タスク名・手順名・メモは出さない(画面共有・録画に映る可能性があるため)。
- アプリを閉じるときは、トレイのアイコンを先に消す(消さないと、プロセスが終わってもトレイに残る)。

### アイコン

- コンセプトは「近未来」+「ペンで描く」。深い青緑の角丸の面に、金属的なペンが斜めに立ち、ペン先から青緑→青に光る線が流れ、先端に回路の端点が灯る。配色は 03章 §3.4.1 と同じ。
- exe のアイコン、ウィンドウ(タスクバー・Alt+Tab)のアイコン、タスクトレイのアイコンに使う。`src/FocusCoach.App/Assets/app.ico`(16〜256px の9サイズ。PNG 形式で内包)。小さいサイズ(32px 以下)は、線を太く・飾りを減らして潰れないようにしている。
- アイコンは `prototype/icon_gen`(WPF の描画から .ico を作る使い捨てツール)で生成した。絵を変えるときは、このツールを直して作り直す。

## 3.6 割り込み対応・出口カード・再入場ガイド・あとでやること・ダイアログ(0.12A で追加)

設計と心理学的な理由は [../review/design-0.12A-interrupt-closure.md](../review/design-0.12A-interrupt-closure.md)。流れと記録は 09章 §9.4.1・§9.4.2・§9.4.2a。

- **割り込み対応ボタン**(S-04): しおりのアイコン +「割り込み対応  F9」。中断することへの心理的な障壁を下げるため、1回押すだけ・入力も確認も無し・警告色を使わない。押すと、状態は「割り込み対応中」、縁の文言は「しおりを挟みました。対応が済んだら F9 で元の作業へ(F10 で再開メモ)」、ボタンは戻る矢印 +「元の作業へ  F9」になる。コンパクト表示(Ctrl で触れるとき)とトレイのメニューにも同じものを置く。
- **出口カード**(S-11a): 対応中の F9 / [元の作業へ] で開く。ミニパネル(またはコンパクト表示)のすぐ下、トレイに格納中は画面の中央。内容: カテゴリ(タスクのプルダウンと同じ: 選ぶか新しい名前を入力、右クリックで一覧から外す。既定は「割込み作業」だけで、最近使った順)、件名(任意)、`完了` / `あとでやることが残る`(選んだときだけ、1行と期限 `期限なし`・`今日`・`明日`・`日付` を出す)、`割り込みで開いたウィンドウを片付ける(n)`(既定 ON、最小化するだけ)。**何も書かずに Enter で閉じられる**。カードの表示中の F9 は Enter と同じ。Esc・×・[まだ対応を続ける] は対応中のまま。画面共有には映さない。
- **再入場ガイド**(S-11b): 出口カードを閉じると、割り込みの直前に使っていた作業ウィンドウを前に出し、その中央・上寄りに重ねる(作業ウィンドウが分からなければ画面の中央・上寄り)。内容: 「元の作業に戻ります」、タスク ─ 手順、次の一手(無ければどこまで)、`{sec}秒で、元の作業に集中しましょう`(設定で変更・非表示可)、満ちていく輪と小さな残り時間、[+30秒] [今すぐ戻る]。初回だけ「この時間の使い方は自由です(深呼吸、お茶、メモの整理など)」。秒の数字は小さく、音・点滅は無し。フォーカスを奪わない。時間切れで薄く消え、直前2秒に入力が無ければ作業ウィンドウにフォーカスを移す。割り込みが `ReentryGuideMinInterruptSec`(既定60秒)未満、または `ReentryGuideSec` が 0 のときは出さず、今までの復帰カード(S-11)を出す。表示中の F9 は新しい割り込み。
- **あとでやること**(S-12): ミニパネルの下に「あとでやること n ・今日まで m」(1件以上のときだけ)。クリック・トレイのメニューで一覧を開く。一覧は 期限切れ → 今日まで → 明日まで → これから → 期限なし の順で、チェックで完了、× で削除、完了は7日間だけ下に畳んで見せる(チェックを外せば戻る)。振り返りに、その作業中に増えたものを出す。画面共有には映さない。
- **ダイアログ**: Windows 標準のメッセージボックスは使わない。お知らせ・確認は、アプリと同じ配色と細いタイトル帯(「FOCUS COACH」・題名・✕・光る線)の `FcDialog` で出す。ボタンは何が起きるかが分かる言葉にする(例: 閉じるときの `閉じない` / `終了して閉じる` / `中断して閉じる`。Enter の既定は記録を失わない `中断して閉じる`)。メモ・手順エディタ・ウィンドウ整理・出口カード・あとでやることも、同じタイトル帯を使う(白い標準のタイトルバーは使わない)。

## 3.7 表示言語の切り替え(0.13A で追加)

設計は [../review/design-0.13A-i18n.md](../review/design-0.13A-i18n.md)。日本語と英語の2言語(辞書に `Strings/xx.json` を足せば言語を増やせる)。

- **前提(2026-11-03、利用者の決定)**: 利用者は自分のメインの言語だけで使う。日本語の利用者は日本語で入力する(英語が混ざることはある)。英語の利用者は英語だけで入力する(日本語は想定しない)。切り替えは、主に最初の設定や、言語の違う人に画面を見せるときのためのもの。

- **言語の決め方**: 設定 `Language` が `auto`(既定)なら、OS の表示言語が日本語のとき日本語、それ以外は英語。`ja` / `en` なら固定。切り替えたら、その言語を保存する(次の起動でも同じ)。
- **切り替えの操作**(実行中でも、作業の状態・タイマー・記録には影響しない。表示だけが替わる):
  - タイトル帯の **`JA` / `EN` ボタン**(▭ – ✕ の左。現在の言語が文字になる。押すと切り替わる)。
  - トレイのメニュー **`Language / 言語`**(見出しはどの言語でも併記。`日本語` / `English`、現在の言語に ● が付く)。
  - グローバルホットキー **Ctrl + Alt + F8**(設定 `HotkeyLanguage`(仮想キー。0 で無効)と `HotkeyLanguageModifiers`(Alt=1・Ctrl=2・Shift=4)で変更できる)。ファンクションキー単独は、Word の F7(スペルチェック)など業務アプリのキーを奪うため既定にしない。登録に失敗したら画面に出す。
- **文言**: 画面に出る文は、すべて辞書から引く(XAML は `{loc:T キー}`、コードは `Loc.T("キー", 引数)`)。開いている画面はその場で替わる(ミニパネル・コンパクト表示・トレイ・開始準備)。メモ・出口カードなど短時間だけ開くウィンドウは、次に開くときから。**利用者が入力した内容(タスク名・手順・メモ・カテゴリ名・あとでやること・件名)は翻訳しない。**
- **既定のカテゴリ**: 内部の名前(`割込み作業`)で保存し、表示だけ言語に合わせる(`Interruptions`)。
- **書体**: 日本語は `BIZ UDPGothic`、英語は `Segoe UI Variable Text` / `Segoe UI`。日付・時間の書き方も言語に合わせる(`10/30` ↔ `Oct 30`、`1時間20分` ↔ `1h 20m`)。
- ログ・例外・シナリオ・設定のキー名は言語に依存させない(英語)。確認用の自動操作は、言語に依存しない `AutomationId` で要素を探す。
