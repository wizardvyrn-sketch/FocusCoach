# 構想イメージ(原文)

ユーザーから受け取った構想イメージをそのまま記録する。
仕様書 `docs/spec/` の出発点であり、仕様と矛盾する場合は `docs/spec/` が正。

## 受領 2026-10-03

・ツール概要
　業務作業集中コーチングアプリ

・利用イメージ
　システムソフト開発担当が利用する。
　業務においてプロジェクトごとに同じような繰り返し作業がある。
　例えばメインタスク「開発計画書」を作成するため、その中でも細分化してサブタスクとして「見積書の確認」
「概略仕様の確認」、「担当作業メンバの確認」「スケジュールの確認」など何ステップかあり
それぞれの事前ステップで作成した資料を参照して作成することになる。
　(サブタスク用の資料はファイルサーバやWebシステムなどサブタスク用の管理システム上にある)

　メインタスクを集中して実行し短い作業時間で完了できるように、作業時間とサブタスク状態を
記録していけるようなツールにしたい。

・利用環境
　Windows端末PCを想定。
　ネットワーク接続も可能。
　Web会議用のイヤホン、マイクは利用可能。

・機能イメージ
　メインタスクの開始と終了まで、過去の同種タスクの作業実績を元にガイドする。

　集中力を維持できるように画面ワークスペースをタスク作業用に一旦全ソフトのウィンドウを最小化。
　必要なウィンドウだけ開いてユーザが作業実施、作業終了したらそこのワークスペースのウィンドウは閉じて元に戻る。
　タスク作業中にアクセスしたローカル、ネットワークフォルダ、web URLは記録したい。
　　何を開いたか記録する方法があるか確認して。

　作業開始の合図や終了後はモチベーションアップにつながるような画面演出を入れたい。
　タスク時間のタイマーや集中用のBGM、作業記録ができる。
　作業記録はボイスからテキストに変換できると良い。(後でオンラインツールで変換でもよい)
　作業後に前回の同種タスクと比較した改善ポイント、集中力の変化を見られるようにしたい。

　メインタスクは使っていく中で登録した同種タスクを後からまとめたり再カテゴリ化できる。

あと、集中が切れたときのアドバイスポップアップも出せるようにしたいので　そのアイディアを次に練って仕様書にまとめられるようにしたい。
